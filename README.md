## 🖥 О игре

**DATA BREACH** — третья игра вселенной **CHAOS REALM**. Это логическая головоломка в стиле "хакерского" пазла. Нужно провести непрерывный путь данных от входа (IN) к выходу (OUT), кликая по соседним узлам сетки.

Но система защищена: заблокированные узлы, ловушки и ограниченное время. Собирай золотые бонусы для дополнительных очков — но они всегда в стороне от оптимального пути. Рискнёшь?

---

## ✨ Особенности

- 🧠 **Процедурная генерация уровней**: каждый уровень уникален, но всегда решаем.
- ⛔ **3 типа препятствий**: блокировки, ловушки, таймер.
- 💎 **Бонусы-дилеммы**: золотые узлы дают +50, но требуют отклониться от пути.
- 📈 **Растущая сложность**: сетка 5×5 → 9×8, время уменьшается, ловушек больше.
- ⚡ **Анимация передачи данных**: после построения пути по линии бежит пакет данных.
- 📺 **Глитч-эффекты**: сканлайны, тряска, случайные блоки.
- 🔊 **Процедурный звук**: клики, соединения, ловушки, победа.
- 📱 **Тач-поддержка**: играй на телефоне.

## 🕹 Управление

| Действие | Как |
|----------|-----|
| Выбрать узел | Клик / Тап по узлу |
| Откатить выбор | Клик по последнему выбранному узлу |
| Вернуться к узлу | Клик по любому уже выбранному узлу |
| Начать заново | Клик по входу (IN) |

---

## 🧩 Типы узлов

| Узел | Описание |
|------|----------|
| 🟢 **IN** | Вход данных. Начни путь отсюда |
| 🔴 **OUT** | Выход. Приведи путь сюда |
| 🟢 Обычный | Свободный узел |
| ⬜ Серый | Заблокирован. Нельзя пройти |
| 💥 Красный (!) | ЛОВУШКА: -5 сек и -20 очков |
| 💎 Золотой | Бонус: +50 очков при сборе |
